## TYPE A: OFFLINE EVENT STRUCTURE (Primary)
COVER: Game IP character art as hero. Campaign hashtag (#GoldenGALA) large. Country + Month/Year. WHITE/LIGHT background. WHIM logo. Bilingual label if CN review expected.
→ PROJECT BACKGROUND & INSIGHTS: Cultural moment stats (what people do/spend during season). 2-3 core insight statements tied to game brand pillars. Core Strategy paragraph. Visual references (precedent global events). MOST DATA-HEAVY SECTION.
→ CAMPAIGN OVERVIEW / ACTIVATION PLAN: 3-phase matrix. Rows: OOH / Offline Event / KOL Marketing+PR. Columns: Phase 1 Pre-Heat / Phase 2 Build-Up / Phase 3 Event. Strategic logic: "#1 OOH action, #2 generate conversation, #3 host event". Alternative campaign names offered.
→ OOH DETAIL: Moving Truck (design mockups, social media mechanics — 3 alternatives with reasoning). Train/Metro Wrap (station count, screen count, line coverage, daily reach). Bangkok BTS = 60 stations, 768 screens, 2.4M users/day.
→ TRAIN WRAP DESIGN: Full-side renders, multiple variants
→ BOOTH DESIGN + ACTIVITIES: 3D mockup. Zones: Main Stage / Prize Redemption / Interactive Experience / IP Creative Showcase / Game Experience
→ ON-STAGE ACTIVITY: Game-specific mechanic. E.g. Angbao Session (red packet mechanic), Golden Ball (gacha mechanic). Participant mechanism, prize arrangement, terms & conditions, total prize pool.
→ VENUE: Name, address, floor, Google Maps, dates, footfall notes, pros/cons honestly stated
→ MERCHANDISE: Table with Item / Design Drawing / Reference. Game-branded everyday objects. Chinese character annotations.
→ EVENT OVERVIEW: 4 activities with icons: #1 KOL & Celeb Showmatch / #2 KOC Tournament / #3 Booth Experience / #4 Drone Show. Booth experience stamp quest flow.
→ STAGE RUNDOWN: Hour-by-hour schedule per event day. Named sessions (parade, tournaments, KOL battles, music, Lucky Angbao).
→ MARKETING PROMOTION PLAN: 3-phase timeline. Per phase: Objective + activities. Hashtags & Effects. Online platforms. Reach estimates (people/day).
→ KOL PROMOTION PLAN: Table — KOL Category × Campaign Phase. Categories: Boys Love / KOL Gaming / Vlog KOL.
→ KOL & CELEB SHOWMATCH ROSTER: Full roster by day + format. Day 1: Boys Love Battle / Day 2: Girls Battle / Day 3: Top Gaming KOL Battle. Groups of 4 per team.
