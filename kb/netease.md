Games: Naraka: Bladepoint, Egg Party (蛋仔派对), Once Human, Racing Master, Saint Seiya Awakening
Primary markets: Thailand + Indonesia + Malaysia (multi-country), Vietnam (Naraka)
Why they hire WHIM: WHIM's SEA local knowledge. NetEase cannot understand TH/ID/MY/PH culture from CN. The pitch is always: "We know your target markets better than you do."

## CRITICAL PRINCIPLE
Every NetEase proposal must demonstrate per-country local knowledge. Never generic "SEA." Always say "Thai players specifically prefer X" and prove it with data. Cultural moment seasonal campaigns are one application — but the core value is always SEA localisation + market intelligence.

## PITCH TYPES
Type A: Multi-country KOL Marketing (primary — TH+ID+MY or TH+VN for new games/seasons)
Type B: Single-country KOL Campaign (anniversary, IP collaboration — Naraka×Nier model)
Type C: Social Media Management (less common — Ragnarok Origin/欢乐互娱 model)

## TYPE A: MULTI-COUNTRY KOL PITCH STRUCTURE (Primary)
COVER: Game logo + campaign title + countries listed. White/light background. WHIM logo.
→ TABLE OF CONTENTS (numbered 01-07 with descriptions — NetEase always gets ToC)
→ MARKET ANALYSIS & INSIGHT (HEAVIEST SECTION — must have real data):
   A. Competitor Mapping: Tier 1 vs Tier 2. Revenue pie charts + Active Users pie charts per country. Source cited (Data.ai or equivalent, date range).
   B. Competitor Summary Matrix: Full table — Launch / Positioning / Visual / Multiplayer / Strength / Weakness / App Size. All competitors vs the NetEase game.
   C. Per-country Content Trend (3 columns: TH / ID / MY): Quote per country summarising content culture. Real content examples from competitor games. Key finding: "Thai = educational/reviewers, ID = group play/honest reviews, MY = humor/competitive"
   D. Market Insight: What's Viral? Per country: TH = BL KOLs (GMMTV — Perth Tanapon × Santa Pongsapak), ID = Multi-KOL summit (5 Kages: Windah + DeanKT + Luthfi + Reza + Miawaug, 4.3M views Part 1), MY = Esports collectives (7GL: Soloz, Feekz, Ombong, XK Penjahat)
→ COMMUNICATION STRATEGY: Game positioning from competitor analysis. Key message per audience. Per-country campaign angle. Hashtag.
→ ROADMAP (5 phases): Phase 1 KOL preheat → Phase 2 Viral stars launch challenge → Phase 3 Fans join for rewards → Phase 4 Top KOL follow-up → Phase 5 KOC/buzzers amplify
→ CONTENT DIRECTION (per country): KOL archetype + content focus + tone per country
→ KOL PLAN (per country roster with tiers)
→ ADDITIONAL RESOURCES RECOMMENDATION (creative ideas outside scope — UNIQUE TO NetEase)
→ BUDGET (per phase AND per country breakdown)
→ CASE STUDY: Track record in same countries being pitched
